## 概述

将官网「安装指南」页改造为「配置指南」：一份面向非技术用户（公职/办公人员）的详细操作手册，覆盖从连接大模型、日常核心功能、效率工具到维护安全的完整使用路径。单页长文 + 锚点目录，图文对照，每一步可照做。

### 需求要点

- 页面改名「安装指南」→「配置指南」，全站引用同步替换，网页地址不变
- 手册内容分四大板块：连接大模型 / 核心功能上手 / 效率工具 / 维护与安全
- 每个功能点给出编号操作步骤 + 实机截图 + 小贴士
- 内容与 Gwork v0.9.17 实机界面一致，面向办公人员说人话

---

## 问题

1. **页面定位与内容错位**：现有页面叫「安装指南」，但安装步骤与下载页重复；用户真正的卡点在装好之后——模型怎么配、知识库怎么建、功能怎么用，完全没有文档支撑。
2. **内容薄且术语化**：现有内容罗列 provider、baseUrl、apiKey、modelId 等术语，目标用户看不懂、不敢照做。
3. **无图文对照**：现有页面零截图，操作类内容没有图对办公用户不够直观。

---

## 目标

- 页面标题、导航、页脚及全站引用统一改为「配置指南」
- 手册覆盖四大板块共 13 个功能点（见功能描述），每个功能点有编号步骤
- 每个板块至少 1 张实机截图，全站截图总数控制在 15 张以内（复用现有 7 张）
- 手册步骤与 Gwork v0.9.17 实机界面逐条核对一致
- 文案面向非技术用户：不出现内部术语，操作路径写清「在哪、点什么、会发生什么」

---

## 非目标

- **不拆多页**：单页长文 + 锚点目录即可承载，避免多页面导航与维护成本
- **不截外部网站图**：DeepSeek 等第三方网站的申请流程只写文字步骤 + 官网链接，不截图（外部页面改版会失真）
- **不做版本差异标注**：手册以 v0.9.17 为基线，旧版本界面差异不逐一说明
- **不覆盖低频边角功能**：只写高频核心路径，功能全集不在本轮
- **部署流程不变**：沿用现有双通道部署，不在本规格范围内

## 功能描述

### §1 页面骨架

页面自上而下四段：

1. **页头**：眉题「配置指南」+ 主标题 + 一句话定位（装好之后从这里开始）。原「安装五步」压缩为一句引导：「还没安装？先去下载页」（链接到下载页）。
2. **锚点目录**：桌面端左侧吸附（sticky）侧栏，列出四大板块与小节，点击平滑跳转到对应小节；阅读时高亮当前所在小节。移动端收起为顶部可横滑的目录条。
3. **正文**：四大板块纵向展开。每个小节 = 小节标题 + 简短引入 + 编号操作步骤 + 实机截图 + 小贴士（可选项）。
4. **尾部**：保留现有「咨询与反馈」区块（预约演示/提交需求/问题反馈三卡），不动。

### §2 板块一：连接大模型

> 配置模型是第一次真正用起来的前提，放最前面。

| 小节 | 内容要点 | 截图 |
|------|---------|------|
| 2.1 申请 API Key（以 DeepSeek 为例） | 什么是 API Key（一把访问大模型的钥匙，说人话）；注册 DeepSeek 开放平台账号；创建并复制密钥；妥善保存的提醒 | 不截图，给官网链接 |
| 2.2 在 Gwork 中配置模型 | 打开设置的模型配置页；添加模型服务：粘贴密钥、填写服务地址与模型名（产品界面若已内置常用服务模板，按实际界面写）；连通性验证（发一句测试消息看是否有回应） | 复用现有模型配置截图 + 按实机补拍 |
| 2.3 配置视觉理解模型 | 视觉理解模型 = 能看懂图片的模型（说人话解释）；两种方式：直接选支持看图的模型，或在模型设置里勾选「多模态」开关；验证方式：对话里发一张图让它描述 | 按实机补拍多模态开关所在界面 |

## 边界情况

1. **移动端长页体验**：锚点目录收起为横滑条；截图宽度自适应不溢出；长页滚动性能可接受（图片懒加载）。
2. **截图与产品版本漂移**：产品后续迭代界面变化后，截图会过时——页头注明「界面以 v0.9.17 为准」，后续版本发版时按需更新截图（不在本轮自动化）。
3. **外链失效**：DeepSeek 官网链接如失效，用户仍可自行搜索「DeepSeek 开放平台」——正文补一句站点名称便于搜索。
4. **深色主题用户**：截图均为浅色主题，正文说明不影响操作（按钮位置一致）。
